# Close IN 메인 메뉴 · 팀 로비 시각 제안

메인 메뉴/팀 로비 구성은 **시각 제안**입니다. 후속 요청에서 사용자가 실제 클라이언트 적용을 승인하여, 매칭 완료 배너와 3초 후 전환만 기존 Unreal 로컬 프로토타입에 연결했습니다. 두 화면의 카드/초대 UI 전체를 Unreal에 통합한 것은 아닙니다. 서버·네트워크는 변경하지 않았습니다. 브라우저의 화면 전환과 타이머는 검토용이며 실제 초대·파티 생성·서버 매칭 기능이 아닙니다.

기존 승인 숲 입구 이미지와 각진 v7 로고, 금빛 테두리·잎 장식·청록 버튼을 공유합니다. 원본 파일을 덮어쓰지 않습니다. 참조 스크린샷은 화면의 역할/이동 관계만 요구사항으로 반영하며 특정 게임의 캐릭터, 비율, 폰트, 파란 산업 디자인은 재현하지 않습니다.

최신 수정본 v7은 **매칭 완료 시 화면 중앙에 제공된 배너를 표시하고 3초를 기다리는 단계**를 추가했습니다. 혼자 있는 팀에서도 매칭 시작 버튼을 표시하고 조작할 수 있습니다. 팀 로비의 오른쪽 위 닉네임은 숨기고, 메인 메뉴의 닉네임/종료는 유지합니다. 화면 안의 “팀 로비” 제목 없이 **320×600px** 플레이어 카드, **104×114px** 중립 프로필과 닉네임을 유지합니다. 초대창/완료 배너는 1920×1080 화면 정중앙(960,540)에 표시하며, 뒤 화면에 불투명도 32%의 어두운 레이어를 적용합니다.

초대 UI는 빈 플레이어 카드 안의 `+ / 초대`입니다. 기본 팀 로비는 본인과 빈 슬롯 두 개, 매칭 시작 버튼을 함께 보여줍니다. 해당 카드의 초대 버튼을 누르면 중앙 초대창이 열립니다. 별도 친구 목록/사이드바는 추가하지 않습니다.

## 결과 보기

`index.html`을 열면 상단 검토 도구로 메인 메뉴 / 팀 로비 / 빈 슬롯 / 초대 창 / 매칭 중을 볼 수 있습니다. 검토 도구는 게임 화면이나 캡처에 포함되지 않습니다.

- `?view=main&capture=1`: 1920×1080 메인 메뉴. 게임 시작, 캐릭터, 닉네임, 별도 종료 버튼.
- `?view=team&capture=1`: 1920×1080 팀 로비. 본인 카드와 빈 초대 슬롯 2개, 뒤로, 팀장 표식, 활성화된 매칭 시작. 화면 제목은 후속 요청에 따라 생략합니다.
- `?view=empty&capture=1`: 동일한 1인 팀/빈 슬롯 상태. 매칭 컨트롤도 유지합니다.
- `?view=invite&capture=1`: 닉네임 필드, 초대/취소가 있는 작은 대화 상자. 초대 버튼은 요청을 전송하거나 팀원을 추가하지 않습니다.
- `?view=searching&elapsed=12&capture=1`: 1인 팀의 매칭 중, 시간, 매칭 취소. 빈 슬롯은 그대로 두고 초대/팀원 상태를 잠급니다. 취소하면 초대를 다시 조작할 수 있습니다.
- `?view=full&capture=1`: 세 명이 모두 있는 예시 팀.
- `?view=full&role=member&capture=1`: 제안된 팀장 권한을 확인하는 보조 상태. 일반 팀원은 매칭 시작 버튼을 조작할 수 없습니다.
- `?view=complete&capture=1`: 완료 배너를 고정해 배치를 검토합니다. 실제 버튼으로 시작하면 약 5초 검색 → 3초 완료 표시 후 `closein:match-complete-next` 검토 이벤트가 한 번 발생합니다. 브라우저에는 미구현 캐릭터 선택/플레이 화면을 꾸며 넣지 않으며 이벤트 이후에도 확인용 배너를 유지합니다.

메인 메뉴의 게임 시작은 브라우저의 예시 팀 로비를 보여주기만 합니다. 캐릭터 상세 메뉴와 실제 종료 동작은 범위에 포함하지 않습니다. 캐릭터 선택은 매칭 이후에 이어질 계획이며 여기에는 캐릭터 아트/선택 패널이 없습니다.

## 매칭 완료 에셋과 클라이언트 연결

사용자 제공 `Art/UI/Matchmaking/CloseIN_MatchComplete_Background_v1_1280.png`와 `CloseIN_MatchComplete_TextOnly_v1_1280.png`를 원본 그대로 겹쳐 사용합니다. 두 파일은 1280×457이며 표시 폭은 1040px, 중앙 정렬입니다. 합쳐진 Banner 이미지와 다른 원본도 보존합니다.

Unreal의 기존 `FWLoginPlayerController` 로컬 임시 흐름은 `PrototypeMatchDelaySeconds=5.0` 이후 완료 배너를 표시하고, `MatchCompleteDisplaySeconds=3.0` 이후 `CharacterSelectionLevel` 또는 비어 있으면 `GameplayLevel`로 이동합니다. 값은 `Config/DefaultGame.ini`에서 조절합니다. 검색 중 취소, 종료, EndPlay에서는 타이머를 정리하고 완료 표시 중에는 로비 조작을 잠급니다. 이동 대상이 없으면 로비를 복구하고 오류 안내를 표시합니다. 실제 서버 매칭 완료 이벤트를 추가한 것은 아닙니다.

## 편집/에셋 구성

- `index.html`: 화면 구조와 정적 텍스트.
- `concept.css`: 색상·타이포그래피·좌표·여백·상태 스타일.
- `concept.js`: 로컬 검토 상태와 예시 닉네임, 시각 타이머. 서버/게임 연결 없음.
- `Components/`: 문자 없는 카드/대화 상자 스킨, 중립 프로필, 초대 기호, 팀장 기호, 뒤로 기호의 SVG 원본과 투명 PNG, 별도 `@2x.png`.
- `DesignSpec.json`: 화면 역할, 팔레트, 원본 경로/해시, 재사용 스킨 참조, 확정/미정 범위.
- `LayoutBounds.json`: 1920×1080 기준으로 렌더링한 각 UI 요소의 실제 위치와 크기.

배경과 로고는 기존 경로를 참조합니다. 버튼은 `../Lobby/Components/`의 스킨을 재사용합니다. 텍스트는 스킨 PNG에 포함하지 않으며 프로필 기호도 별도 이미지입니다. 카드/대화 상자의 게임용 PNG는 160×120, 고해상도 자료는 320×240입니다. UMG Box의 Margin은 Left/Right 0.2, Top/Bottom 0.2666667(32px) 기준입니다. 기호 이미지는 일반 Image로 사용합니다. SVG/CSS/텍스트는 계속 편집할 수 있습니다.

폰트 파일은 재배포하지 않습니다. 시안은 OS의 맑은 고딕을 사용하므로 추후 Unreal 폰트 선정 시 한글 모양과 자폭은 다시 확인해야 합니다.

## 미정 및 검증 범위

**혼자서도 매칭을 시작할 수 있다는 것은 사용자 지시로 확정**되었습니다. 빈 슬롯 자동 충원 여부는 여전히 **미정**이며, 시안의 검색 중 슬롯을 임의의 팀원으로 채우지 않습니다. 팀장이 매칭을 시작한다는 것은 이번 제안의 화면 흐름이며 서버 권한 구현의 증거가 아닙니다.

브라우저 렌더·화면 이동·초대 입력·매칭 취소/잠금·완료 배너 중앙 정렬·5초/3초 순서를 확인했고 외부 요청은 없습니다. 이번에 허용된 클라이언트 6개 파일을 제외한 코드와 제공 이미지 등 57개 보호 파일의 SHA256이 동일합니다. 변경한 두 C++ 번역 단위는 MSVC `/Zs` 구문 검사로 확인했습니다. 전체 Unreal 빌드/UHT/링크/실행/패키징은 아직 검증하지 않았습니다.
