# Round 01 v2 — 숲과 암벽 밀도 수정 시안

이번 결과물은 **로우폴리 공간 시안**이다. 최종 아트는 더 사실적인 숲·암반을 지향한다는
요청을 기록하되, 이번 수정에서는 고해상도 텍스처나 실사 에셋 대신 배치·밀도·동선을 다룬다.
v1은 `Art/Maps/Round01`과 기존 Unreal 레벨에 그대로 보존했다.

## 변경점

| 항목 | v1 | v2 |
|---|---|---|
| 캠프 수 | 12개 | 8개: 진영 접근 캠프 4개 + 중립 캠프 4개 |
| 스폰에서 가장 가까운 캠프 | 중심 간 약 23m | 중심 간 최소 약 42m |
| 캠프 사이 간격 | 가까운 캠프들이 연속 배치됨 | 중심 간 최소 약 30m |
| 벽 형태 | 분리된 원형 바위섬 | 길쭉하고 꺾인 연속 암벽·숲 구역 |
| 구조물 배치 | 넓은 초록 지면에 소수 섬 | 통로와 공터를 확보하고 그 사이를 숲·암벽으로 채움 |
| 식생 | 드문 나무, 작은 수풀 | 밀집 수관·외곽 숲·낮은 덤불·쓰러진 나무 추가 |
| 표현 수준 | 로우폴리 | 로우폴리 유지 |

맵의 지면은 계속 **112 × 112m**, 중앙의 비워진 전투 공간은 **지름 36m**다.
좌하단·우상단의 모닥불 스폰 공간도 유지했다. 초기 선택지는 외곽 사냥 경로와
중앙 직행 경로로 나뉜다. 주요 길은 폭 4.5~6m이며, 캠프 공터의 반경은 5.2~5.8m다.
캠프 주변 장식물이 차지하는 부분을 감안해 중앙에 전투 공간을 남겼다.

## 캠프 배치

Blender 기준 **+X=북쪽/위, -Y=동쪽/오른쪽**이며 단위는 m다.
Unreal 기준은 **+X=북쪽/위, +Y=동쪽/오른쪽**이다.
시안의 디자인·크기·동선은 유지하고 메시·기준점·카메라를 함께 회전했다.
Unreal에서 +X 위쪽 탑뷰는 Outliner의 `Round01_NorthTopCamera`를 우클릭 → Pilot으로 확인한다.
이미 열려 있던 에디터는 이전 뷰를 기억할 수 있으므로 레벨을 다시 열고 이 카메라를 사용한다.

| 캠프 | 중심 X,Y | 반경 | 역할 |
|---|---|---|---|
| A1 | -2,43 | 5.3m | A팀 서쪽 첫 사냥 후보 |
| A2 | -43,-1 | 5.3m | A팀 남쪽 첫 사냥 후보 |
| B1 | 2,-43 | 5.3m | B팀 동쪽 첫 사냥 후보 |
| B2 | 43,1 | 5.3m | B팀 북쪽 첫 사냥 후보 |
| NW1 | 39,40 | 5.8m | 좌상단 외곽 중립 캠프 |
| NW2 | 17,20 | 5.2m | 좌상단 중앙 접근 중립 캠프 |
| SE1 | -39,-40 | 5.8m | 우하단 외곽 중립 캠프 |
| SE2 | -17,-20 | 5.2m | 우하단 중앙 접근 중립 캠프 |

기능상 배치는 180도 회전 대칭이다. 개별 중립 캠프가 양쪽 스폰에서 등거리인 것은 아니다.
반대편 중립 지역에 대응하는 접근 조건을 둔다. 몬스터 수·등급·보상·리젠은 아직 정하지 않았다.
각 캠프의 몬스터 기준점 3개는 예시 슬롯이며, 최종 몬스터 수를 제한하지 않는다.

## 검사 범위

`Validation.json`은 1m 격자에서 숲·암벽 점유 셀과 0.6m 캐릭터 여유를 고려한 경로 계산이다.
양쪽 스폰에서 모든 캠프와 중앙까지 총 18개 경로를 확인한다.
캠프와 스폰 간 최소 직선 거리, 캠프끼리의 최소 거리, 숲 구역 점유 면적도 기록한다.
이는 UE NavMesh나 실제 캐릭터 주행 테스트가 아니다.

계산 결과: 스폰→첫 캠프 경로는 약 44.1~49.6m(현재 이동 속도에서 7.3~8.3초),
캠프 중심 간 최소 거리는 29.73m, 스폰→캠프 중심의 최소 직선 거리는 42.01m다.
숲·암벽 생성 영역은 4,298m²(지면의 약 34.3%), 연결된 지형 구역은 14개,
나무는 외곽을 포함해 216그루다.
`Geometry_Verification.json`에는 실제 암벽 메시를 대상으로 한 1,087회 수직 교차 검사를 기록했다.
캠프·스폰·중앙 공터 내부와 경로 중심선에 암벽이 침범한 곳은 0건이었다.

`Unreal_Import_Report.json`은 임포트 결과, `Unreal_Verification.json`은 저장 후 재로딩 검사다.
지면 색상, 재질, 충돌 프로필, 57개 배치 기준점과 A팀 깃발 좌표를 검사한다.
미리보기는 Blender 렌더이고, Unreal 파일 검증은 화면을 띄우지 않는 NullRHI 모드다.
최초 Unreal 저장·재검증은 오류 0건, 경고 0건으로 완료됐다.
축 변경 후 동일 항목과 카메라 방향을 다시 검사했으며 `NorthAxis_Unreal_Verification.json`에 기록했다.
이번 전체 재임포트는 오류 0건이며 일부 FBX 접선 경고와 NavMesh 부재 경고가 있었다.
단색 로우폴리 시안은 Built-in 접선 계산을 사용한다. 최종 아트에 노멀맵을 적용할 때는
정식 UV와 해당 에셋에 맞는 접선 설정을 함께 준비한다.

지면·암벽은 충돌하고, 나무·소품·수풀·불 모형은 충돌하지 않는다. 나무는 주로
통행 불가 암벽 위에 배치하여 이동 구역과 구분했다. 자기장, 스폰, 몬스터,
수풀 은신과 시야 처리는 이번에도 구현하지 않았다. 배치 기준점만 제공한다.
실제 쿼터뷰 카메라에서 수관에 가리는 정도와 전투 가독성은 플레이 단계에서 확인해야 한다.

## 재생성

프로젝트 루트에서:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --threads 4 --python-exit-code 1 --python 'Scripts\Blender\CreateRound01DenseMap.py'
```

`-- --no-render`는 렌더 생략, `-- --overview-only`는 전체 미리보기만 생성한다.
생성기는 v2 출력 파일을 다시 쓰므로 수동 편집본은 다른 이름으로 보관한다.
UE 임포트/검사 스크립트는 `-Round01Variant=v2` 옵션으로 v2를 선택한다.
이미 완성된 UE 레벨의 자동 덮어쓰기는 거부한다.
