# 1라운드 숲 장식 비교 맵

동일한 지형과 조명에 장식 구성을 다르게 적용한 두 개의 팀 검토용 맵입니다.

| 버전 | Unreal 맵 | 장식 방향 |
|---|---|---|
| 1. 자연형 | `/Game/Map/L_Round01_WarmForest_Nature` | 큰 이끼 바위 무더기 28곳, 쓰러진 나무·통나무 27개, 입체 관목 군집 316곳과 작은 식생 |
| 2. 탐험 흔적형 | `/Game/Map/L_Round01_WarmForest_Explorer` | 큰 바위 무더기 28곳, 입체 관목 군집 330곳, 작은 천막 4곳, 보급품 묶음 14곳과 벤치·등불 |

공통 크기는 112×112m이며, +X가 북쪽/화면 위, +Y가 동쪽/화면 오른쪽입니다. 중앙 전장, 캠프 8개, 스폰 2곳, 기존 나무 높이와 길·충돌·조명은 같은 기준을 사용합니다. 기존 `L_Round01_WarmForest`와 HQ/Study 맵은 보존합니다.

장식은 비교용 시각 요소이며 이동을 막지 않습니다. 천막·상자에 상점·루팅 기능이 구현된 것은 아닙니다.

최신 작업본(R6)은 바닥 메시·재질·모래 흔적과 기존 지형 형상을 그대로 사용합니다. 길목을 가리던 나무를 양쪽 10그루씩 정리해 각 맵에 196그루가 남습니다. 해당 구간의 높은 관목·바위도 낮추고 낮은 바위·통나무·그루터기 18개씩을 보강했습니다. 다른 구역의 풍성한 식생은 유지합니다.

몬스터 캠프는 총 8곳입니다. 외곽 6곳은 기존 돌 반원·목재 표식을 사용하고, 사방이 열린 내부 2곳(Camp_NW2/SE2)은 입구나 경계가 없는 돌무더기·짧은 목재·상향 발자국 그루터기를 사용합니다. 캠프 중앙 반경 2.55m를 비웠으며, 원래 캠프 좌표와 몬스터 슬롯은 유지합니다. 실제 몬스터 생성 기능을 추가한 것은 아닙니다.

## 확인용 화면

프리뷰 이미지는 로컬 확인용으로만 보관하며 Git에는 포함하지 않습니다. 각 버전의 로컬 `Previews` 폴더에 전체 화면 `Game_Overview_Visibility_R6.png`, 양쪽 길목 `Game_Junction_West_R6.png` · `Game_Junction_East_R6.png`, 내부 캠프 `Game_InteriorCamp_Open_R6.png`가 있습니다. 저장소를 새로 받은 환경에서는 해당 이미지가 제공되지 않으므로 위 Unreal 맵을 열어 확인하세요.

로컬 전체 화면은 같은 카메라에서 저장한 2160×1350px 실제 Unreal 실행 캡처입니다. 각 맵의 기존 외곽 차단 88곳, 확장 벽 차단 147곳, 길·캠프 보호 612곳 검사를 통과했습니다.

- 캠프 장식은 `Dressing_Camp_*_Visual`이라는 별도 액터 8개이며 `Dressing/<버전>/MonsterCamps` 폴더에서 찾을 수 있습니다.
